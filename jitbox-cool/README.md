# クールBOXチャーター便（ダミーLP）

`https://www.jitbox.co.jp/lp/cool/` の模写依頼を受けて作成したモックアップです。

## 前提・注意

- **原本のページはこの環境から閲覧できませんでした**（ネットワークポリシーによりドメインへの接続が拒否されました）。
  そのため本ファイルは「日本のBtoB物流LPの定番構成」＋「クール便らしい寒色系配色」で構成した**推定版**です。
  スクリーンショット／HTMLソースをいただければ、構成・配色を原本に寄せて作り直せます。
- **テキスト・数値・社名・電話番号・料金・実績・お客様の声はすべてダミー／架空**です。
- `<meta name="robots" content="noindex">` を付けています。公開する場合は文言・画像・ロゴを差し替えたうえで外してください。

## 技術

- 単一HTMLファイル。ビルド不要、外部依存はGoogle Fontsのみ。画像は全てインラインSVG／CSSなので画像ファイル不要。
- レスポンシブ（PC / タブレット / スマホ）、横スクロールなしを確認済み。
- スクロール表示アニメーションは `IntersectionObserver`、`prefers-reduced-motion` に対応。
- フォームは `preventDefault()` のデモ動作で、ネットワーク送信は一切行いません。
